Authoritative ranking path

From responses to defensible tiers

A single sorted score list overstates what the data know. This implementation separates a convenient display order from the confidence-backed partial order used for claims.

Calibrate an anchor bank

Fit estimable items on an independent historical cohort under a selected 1PL, 2PL, or 3PL model. Freeze item IDs and parameters.

Estimate EAP posteriors

Align new responses to the bank and integrate each entity's ability posterior over normal quadrature nodes. Missing responses remain allowed.

Resolve pairwise claims

Compute practical superiority directly from posterior mass instead of comparing point estimates or overlapping standard errors.

Publish confidence tiers

Use the full pairwise dominance graph. Models in the same tier remain unresolved even when their posterior means produce different display ranks.

Declare A above B only if   P(θA > θB + ε | observed responses, fixed item bank) ≥ 1 − δ
Interpretation
The total order is not the scientific conclusion.

Posterior-mean order is included for navigation. Pairwise probabilities and tiers decide which differences are supported. SWE-bench entities are model-plus-agent systems, never isolated base models.

Prediction-assisted randomized evaluation

Cheap evaluation without IRT

Historical response structure predicts where a new model is likely to succeed, but the final score does not have to trust that prediction. Randomized exploration and logged inclusion probabilities correct the surrogate's errors.

Learn response structure

Fit a ridge-regularized low-rank surrogate on completed historical models. No item-response curve or latent ability model is assumed.

Probe with sentinels

Evaluate a small content-stratified set and adapt the historical prediction to the new model without consulting hidden outcomes.

Randomize acquisition

Mix predicted residual risk with mandatory stratified exploration. Record every item's inclusion probability before revealing outcomes.

Correct and resolve

Apply a propensity-weighted residual correction. Rank point estimates for display, but claim separation only for paired gaps whose intervals clear epsilon.

score_hat = mean(qi) + (1 / N) Σsampled i (yi − qi) / πi

Honest boundary

Scope boundary
This is an exploratory policy benchmark.

Reproduce and extend

Run the ranking workflow

Calibrate on an independent historical matrix whenever possible, save the bank, then reuse it for every future cohort with the same item IDs.

1 · Calibrate and rank

uv run python scripts/rank_models.py \
  --matrix path/to/new_responses.parquet \
  --calibration-matrix path/to/history.parquet \
  --save-item-bank artifacts/item-bank.json \
  --output artifacts/ranking.json \
  --epsilon 0.1 --confidence 0.95

2 · Reuse the anchored scale

uv run python scripts/rank_models.py \
  --matrix path/to/later_responses.parquet \
  --item-bank artifacts/item-bank.json \
  --output artifacts/later-ranking.json \
  --epsilon 0.1 --confidence 0.95
uv sync --all-groups --all-extras
uv run pytest
uv run ruff check .
uv run mypy src scripts tests
Claims discipline

What this report does not claim

Deferred

Fixed-confidence calibration

No anytime-valid epsilon-inversion guarantee or 200-seed sealed coverage result has been established.

Deferred

Item-bank uncertainty

Ranking posteriors are conditional on fixed calibrated parameters; full item-parameter uncertainty is not integrated.

Deferred

Dollar or live-provider savings

No paid provider calls were made. Reduced replay uses normalized unit cost, not token- or task-priced dollars.

Not supported

Rank-aware superiority

The reduced experiment does not support a claim that rank-aware allocation beats CAT-SE or balanced random.

Interpret carefully

One-dimensional ability

A global latent score can hide domain tradeoffs. MMLU decisions should also report subject-level or preregistered weighted rankings.

Entity semantics

SWE-bench systems

Submission rows combine a model with an agent harness, tools, and scaffolding. The resulting order is a system ranking.
